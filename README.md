# 🏋️ FitLog

FitLog is a responsive workout management web application built with Next.js. It allows users to explore workouts, view detailed exercise information, create a daily workout plan, and save workouts for later.

## 🛠️ Technologies Used

* **Next.js** — Application framework
* **React** — UI development
* **JavaScript (JSX)** — Programming language
* **Tailwind CSS** — Styling and responsive design
* **React Context API** — Global state management
* **React Toastify** — Toast notifications
* **LocalStorage** — Persisting plan and saved workout data

## ✨ Key Features

1. 🏋️ **Workout Library**
   Browse workouts with information such as workout name, category, equipment, duration, calories, and rating.

2. 📋 **Today's Workout Plan**
   Add workouts to today's plan and manage them from the My Plan page.

3. ❤️ **Save Workouts**
   Save workouts for later and access them from the Saved tab.

4. 📊 **Workout Tracking**
   Track total exercises, workout duration, and calories, and mark completed workouts as done.

5. 📱 **Fully Responsive Design**
   The application is optimized for mobile, tablet, and desktop screen sizes.
